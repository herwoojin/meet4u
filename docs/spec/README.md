# PromiseU (Meet4U) 재현 명세 패키지

다른 프로젝트에서 이 제품을 **처음부터 동일하게** 만들기 위한 문서 4종.

## 문서 구성

| 파일 | 내용 | 누가 읽나 |
|---|---|---|
| [`PRD.md`](./PRD.md) | 제품 요구사항 — 무엇을 만드는가 | 기획자 · 개발자 · AI 에이전트 |
| [`TRD.md`](./TRD.md) | 기술 요구사항 — 어떻게 만드는가 | 개발자 · AI 에이전트 |
| [`ERD.md`](./ERD.md) | 데이터 모델 + Firestore 규칙 전문 | 개발자 · AI 에이전트 |
| [`PROMPT.md`](./PROMPT.md) | AI 코딩 에이전트용 단계별 지시문 | AI 에이전트에 붙여넣기 |

## 사용 순서

### 사람이 직접 만들 때
1. `PRD.md` 전체 정독 — 특히 **3장(회원 등급)**, **8장(완료 기준)**
2. `TRD.md` **9장(알려진 함정 11가지)** 먼저 읽기 — 실제로 겪은 버그 목록
3. `ERD.md` 4장 규칙을 그대로 Firestore 에 배포
4. `PROMPT.md` 의 8단계 순서대로 구현

### AI 에이전트에게 맡길 때
```bash
# 1. 새 프로젝트에 이 폴더를 복사
mkdir -p new-project/docs/spec
cp PRD.md TRD.md ERD.md PROMPT.md README.md new-project/docs/spec/

# 2. 에이전트에게 PROMPT.md 의 "0. 마스터 프롬프트" 를 붙여넣기
```

## 이 제품의 핵심 3가지

1. **프로젝트(동호회) 단위 격리** — 프로젝트에 속하지 않으면 아무것도 보이지 않는다
2. **트랜잭션 기반 정원 관리** — 게스트 모집의 참가/취소/대기 승격은 정원 초과가 절대 없어야 한다
3. **다국어 실시간 소통** — 20종 언어 자동 번역 + 발음 표기 + 음성 통역

## 가장 흔한 실수 TOP 5

`TRD.md` 9장에 11개 전부 정리되어 있지만, 특히 이 5개는 반드시 처음부터 대응할 것:

| # | 실수 | 결과 |
|---|---|---|
| 1 | 프로필을 `getDoc` 으로 한 번만 읽음 | 관리자인데 메뉴가 회색, 새로고침해야 정상 |
| 2 | `ProjectContext` fallback 에 `projects.length === 0` 조건 추가 | 신규 가입자가 남의 프로젝트 일정을 전부 봄 (보안 사고) |
| 3 | SW 알림 태그에 `Date.now()` 사용 | 예전 알림이 계속 쌓여 잠금화면 도배 |
| 4 | 클러스터 내부 `<Marker ref>` 사용 | 지도 페이지 통째로 크래시 |
| 5 | 초대 후보 fallback 을 "전체 users" 로 설정 | 전 회원 개인정보 노출 |
